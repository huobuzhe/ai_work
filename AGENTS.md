## Agent skills

### Issue tracker

Issues and specs live in this repo's GitHub Issues (huobuzhe/ai_work), managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles keep their default label names. See `docs/agents/triage-labels.md`.

### Domain docs

multi-context: one `GLOSSARY.md` per subproject, with a root `GLOSSARY-MAP.md` pointing at them. See `docs/agents/domain.md`.

### Research notes

Platform API shapes, field-type codes, capability matrices, and other first-hand research conclusions live in `docs/research/*.md` (one file per topic, named by platform/subject). Before dispatching research, `ls docs/research/` and reuse an existing note on the same topic rather than re-investigating.
