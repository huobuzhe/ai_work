# 表格自动化工作台

> 一个本地优先的表格自动化工作台——把日常表格琐事收进一键按钮，零凭据、Excel 直接可用。

## 这是什么

日常里总在重复同一类表格操作：建一张表、按固定格式填数、反复套同一批公式、按某些条件批量改数据……这些事单看都不难，但一次次手动做既费时又容易出错。

这个项目想做的事很朴素：**把这些反复出现的表格操作，一次配置、固化成按钮，之后一键复用。** 你只需要准备好数据，点一下按钮，剩下的交给它。

- **本地优先、零凭据**：以本地 Excel 为主，打开就能用，不需要注册账号、不需要填写任何密钥、数据也不必上传。
- **一键固化**：把「建表 → 填数 → 套公式 → 按条件改数」这类日常动作组合成按钮，反复调用，稳定复现。

## 当前状态

这是一个**早期、进行中的项目**。目前**本地 Excel 这条路径已经可用**；面向云端表格（如飞书、腾讯文档）的能力**仍在规划与验证阶段，尚未经过实测**。我们会在真正跑通、验证通过之后才把它当作可用能力对外介绍——在达成之前，不会把它写成已经支持。

## 我们的原则

- **能不编就不编**：能力没验证，就如实说没验证，不夸大、不用漂亮话糊弄。
- **不静默替你改**：如果某类操作当前还不支持，会明确告诉你并停下，而不是悄悄把结果改坏、或用看起来成功的方式糊弄过去。
- **少即是多**：先把一条路径走扎实，再谈扩展。
