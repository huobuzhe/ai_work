# dsh-workbench · 表格工作台

![version](https://img.shields.io/badge/version-1.2.0-blue) ![license](https://img.shields.io/badge/license-MIT-green) ![local--first](https://img.shields.io/badge/local--first-零凭据-green) ![tests](https://img.shields.io/badge/tests-571%20cases-success)

> 一个跑在 **DSH（DeepSeek Harness）宿主里的 Excel 工作台插件**：打开 `.xlsx / .xls / .csv` 时表格原样显示，右下角多一个不遮挡的浮窗按钮；点开「表格工作台」，**选一个动作（或写一句话）→ 逐格预览「改前 → 改后」→ 点确认才真正写回文件**。本地运行、零云凭据、每一步都可预览、可回滚。

---

## 一、这是个什么项目

### 一句话

把「日常反复做的表格操作」收进一个**不打扰原表的浮窗**里——你点一个动作或写一句话，它先把你数据**逐格**改成什么样摆给你看，你确认了才落盘。**不做黑盒自动改，一切可预览、可拒绝、可回滚。**

### 解决什么问题

日常里的表格工作总在重复同一类动作：按主键从另一张表补值、对调两列、按条件批量改、反复套同一批公式、按某列去重、统一加前缀、按部门统计工时……单看都不难，但一次次手动做既费时又容易出错，而且「改错了」往往不可见。

这个项目把这些操作变成**确定性的、可预览的一键动作**：每个动作都有类型化参数校验（缺必填 / 类型错 / 列不存在，预览前就挡下），每个结果都逐格展示再确认，落盘前你的文件一个字节都不动。

### 关键定位

- **宿主内插件，不是独立网页**：它挂在 DSH 宿主里，随「打开表格文件」出现；没有独立 URL，不需要单独启动。
- **本地优先、零凭据**：以本地 Excel 为主，`Python + openpyxl` 读写文件，公式重算用本地 LibreOffice Kit。**不需要账号、不需要密钥、数据不上传**。
- **确定性优于「聪明」**：一句话理解是**关键词匹配的本地解析器，不是大模型**——认得出就做、认不出就明确报错，绝不瞎猜、绝不静默改坏数据。
- **诚实边界**：能力没验证就如实说没验证；不支持的平台/动作明确禁用并提示，不偷偷降级糊弄。

## 二、具体功能

### 2.1 界面形态

- 打开表格后，**表格本身还是宿主原生可编辑网格**（和平时一样，不替换、不影响原有编辑）。
- **右下角一个 ⚙ 浮窗按钮**（不遮挡表格）；点开是「表格工作台」浮窗面板，标题栏显示**当前文件名**。
- **切换文件**时面板自动切到新文件、回到初始默认态；再点 ⚙ 收起。

### 2.2 十三个一键动作

每个动作都是「选好参数 → 看逐格影响预览 → 确认才落盘」。参数由类型化声明层 `paramSpec` 做**封闭校验**：未知字段、缺必填、类型/枚举不合法，一律在预览前挡下，**非法配方绝不执行**。

| # | 动作 | 做什么 | 一句话例子 |
|---|---|---|---|
| ① | `extract` 提取字段 | 从**另一张来源表**按主键把某列值搬过来（可新建列） | 「从外勤登记表把邮箱提到备注列」 |
| ② | `swap` 调换两段字段 | 两列内容对调（整列换 / 只换命中行，未命中行强制披露） | 「对调工时和时薪两列」 |
| ③ | `conditional` 带条件增删 | 对**满足条件的行**加值 / 清空 | 「工时大于 150 的备注写『加班』」 |
| ④ | `function` 自定义函数计算 | 同行四则运算写新列（多操作数 `+ - * /`、括号、优先级、一元负号；可**写数值或写 A1 公式**） | 「应发 = (工时*时薪)+奖金」 |
| ⑤ | `dedupe` 按主键去重 | 主键重复的只保留一条、其余重复行**非主键列清空**（不物理删行） | 「按姓名去重保留首条」 |
| ⑥ | `replace` 文本替换 | 子串替换 / 整列赋值（空+空会拦截，不清整列） | 「部门里的『销售』换成『市场』」 |
| ⑦ | `fill` 空值填充 | 只填**空**单元格，已有值不动 | 「备注空的填『待补』」 |
| ⑧ | `trim` 去首尾空格 | 去文本首尾空白，无空格行不进预览 | 「姓名去掉两边空格」 |
| ⑨ | `case` 英文大小写 | 英文转大写 / 小写 | 「邮箱转小写」 |
| ⑩ | `affix` 加前后缀 | 统一加前缀 / 后缀 | 「工号前面加『EMP-』」 |
| ⑪ | `sort` 按列排序 | 按任意列升/降序**重排整表行顺序**（行内容不变，数值按数值、文本按字典序） | 「按工时从高到低排」 |
| ⑫ | `highlight` 单元格标色 | 满足条件的单元格刷底色（黄/红/绿/蓝柔和色），值不变；支持**多条件 → 多色规则组** | 「工时>160 标红；>140 标黄」 |
| ⑬ | `sum` 汇总统计 / 透视 | 对一列或多列做合计/平均/计数/最大/最小，可**一次多列多聚合**，还可按某列或**多级多列分组透视**；结果写进独立「汇总」sheet，**不改原数据表** | 「按部门统计工时合计」「按部门和月份两级汇总」 |

### 2.3 多动作流水线（批处理）

一条流水线可**串多个动作、一次执行**：把若干步（如「先调换两列 → 再按工时排序 → 再汇总」）排成一列，逐格预览整条链的最终影响，确认后一次性落盘。

### 2.4 汇总与透视（`sum` 详解，结果永远写独立「汇总」sheet）

- **一次多列 / 多聚合**：`多列汇总` 填 `列名:聚合;列名2:聚合2`（聚合取 `sum/avg/count/max/min`），一次产出多行结果。
- **按列分组透视**：`分组列` 填某列（如「部门」）→ 按它分组、每组一行、各规格项作列，产一张透视表（组顺序=首次出现顺序，空值归「（空）」组）。
- **多维透视（多级分组）**：`多级分组` 用分号分隔多列（如 `部门;月份`）→ 按多列**分层分组**、表头为各级取值，一行一个组合（如「销售 / 1月」「销售 / 2月」）。
- **绝不改原表**：结果统统写进独立工作表「汇总」（同名先删再建、重跑一致）；原数据表一个单元格都不动。某列/分组列不存在 → 预览前点名列名拦截，不静默算错。

### 2.5 四种触发方式（从简到手写）

1. **一键动作（最省事）**：点动作芯片（如「调换两列」），表单里用下拉选好字段，点「预览」。
2. **一句话理解**：顶部输入框写一句话（如「对调工时和时薪」「条件 工时大于150 标记加班」），点「理解」→「预览」。
3. **按钮库固化**：任何一次操作确认后，可「固化」成命名按钮；下次一键重跑，或改名 / 改参数 / 删除。
4. **新建表格**：浮窗底部可建空白表（自选主键列）、从模板建表、或上传现有 CSV/XLSX（校验格式/加密/宏/改名伪装后建）。

### 2.6 影响预览（改之前先看清楚，改之后留痕）

- **逐格 before → after** 表格化预览：受影响单元格**黄底高亮 + 显示 `原值 → 新值` 箭头**；执行后去箭头、保留高亮，方便对照。
- 摘要行「影响 N 行 / 共 M 行」；部分改动（如半换）**强制披露**「N 行交换、M−N 行不变」。
- **支持新建列**：extract 写到、function 输出列、conditional 目标列都可新建列。

### 2.7 五步主流程 + 封闭校验 + 可回滚

「理解 → 校验 → 预览 → 确认 → 固化」五步，每一步都能看到真实计算，任一步校验失败都不落盘。CONFIRM 前会对配方再跑一次校验（纵深防御），防止状态漂移后执行失效配方。

### 2.8 可选：一句话理解接真 LLM（离线默认关）

关键词解析器可无缝替换为真 LLM（任意 OpenAI 兼容网关，如 DeepSeek/OpenAI）——适配器纯新增、**离线默认关闭、永不阻断**：LLM 抛错/超时/返回非法 kind 一律静默回落到关键词解析。见 [使用手册第十四节](docs/usage-guide.md)。

### 2.9 平台与能力位（诚实边界）

- **本地 Excel**：公式能力四格全绿（真跑写公式 → LibreOffice 重算 → 读回缓存值闭环）。
- **飞书 / 腾讯**：结构化动作（extract/swap/conditional 等）可用，链路已持真实凭据真跑通「建表→写值→读回」；但**公式能力位结构上 false**（云端 V3/CellValue 无公式字段、无重算、无读计算值）——`function` 在这两个平台**直接禁用并提示**，**绝不偷偷把公式算成固定值**。

## 三、安装

### 前置条件

- 已安装 **DSH（DeepSeek Harness）**，能找到它的 profile 目录（一般 `~/.dsh/profiles/<profile名>/`，如 `~/.dsh/profiles/desktop/`）。
- **Python 3 + openpyxl**（读写 xlsx 用）：
  ```bash
  python -c "import openpyxl; print('ok')"
  ```
  没有就装：`pip install openpyxl`。

### 方式 A：一条命令装（推荐）

```bash
git clone https://github.com/huobuzhe/ai_work.git && bash ai_work/workbench/scripts/install.sh
```

脚本默认装到 `~/.dsh/profiles/desktop`；换 profile：
```bash
DSH_PROFILE_DIR="$HOME/.dsh/profiles/我的profile" bash ai_work/workbench/scripts/install.sh
```
装完**重启 DSH**，打开任意 `.xlsx/.xls/.csv`，右下角出现 ⚙ 浮窗按钮 → 装好了。

> **离线 zip 版（无 git 的机器）**：从 [Releases](https://github.com/huobuzhe/ai_work/releases) 下载 `dsh-workbench-1.2.0.zip` 后一行命令：
> ```bash
> unzip -o dsh-workbench-1.2.0.zip && bash dsh-workbench/scripts/install.sh
> ```

### 方式 B：手动安装

1. 把 `workbench/` 放到固定位置（如 `F:\plugins\workbench` 或 `~/plugins/workbench`）；
2. 目标 profile 的 `package.json`：`dependencies` 加 `"dsh-workbench": "link:<路径>"`，`dsh.profile.bundles` 数组加 `"dsh-workbench"`；
3. 建 `node_modules` 软链（Windows `mklink /J dsh-workbench <路径>`；macOS/Linux `ln -s <路径> dsh-workbench`）；
4. 重启宿主。

更细的排障（没浮窗 / 启动崩溃 / 表格打不开 / 公式空白）与卸载，见 **[workbench/INSTALL.md](workbench/INSTALL.md)**。

## 五、当前状态

**本地 Excel 路径已完整可用（v1.2.0）**：13 个动作 + 五步主流程 + 流水线 + 透视/多级透视 + 可选真 LLM。测试覆盖 571 例（550 通过 / 0 失败 / 21 跳过，跳过项为需本机 LibreOffice 或云端凭据的环境相关用例），CI 在 ubuntu/windows × Node 20/22 四 job 全绿。

面向云端表格（飞书、腾讯）的结构化动作链路已持真实凭据跑通，但公式能力位结构上不支持——**只有真正验证通过的能力才会被写成已支持，达成前不夸大**。

## 六、我们的原则

- **能不编就不编**：能力没验证，就如实说没验证，不夸大。
- **不静默替你改**：不支持的操作用明确告诉你并停下，不悄悄改坏、不用「看起来成功」糊弄。
- **少即是多**：先把一条路径走扎实，再谈扩展。
