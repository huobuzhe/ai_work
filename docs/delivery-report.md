# 交付报告：表格工作台（dsh-workbench）

> 更新于 2026-11-21 · 仓库 `huobuzhe/ai_work` · 最新版本 **v1.2.0**
> 本报告是对外可分享的成果小结；详尽逐波清单见 [交付账本](research/delivery-ledger.md)，安装/使用见 [workbench/README.md](../workbench/README.md) 与 [INSTALL.md](../workbench/INSTALL.md)。

## 一句话总结

把「建表 + 日常繁琐表格操作」收进一个**确定性**的 Excel 工作台：宿主打开 .xlsx/.xls/.csv 时原表原样显示（原生可编辑），右下角只多一个不遮挡的浮窗按钮，点开是「表格工作台」面板——一句话或一键动作 → **逐格预览** → 确认才落盘。先在**本地 Excel 零凭据**跑通最小闭环，再沉淀出**可交实现的云端 adapter 规格**（飞书优先、腾讯次之），此后经过二十余波增量，做成一个可安装、可发布、带 CI 的完整插件，最新 **v1.2.0** 已发布 Release。

- **两份规格 + 26 张实施票**：核心闭环、模板库、公式重算、作用范围与条件、配方校验与预览卡、按钮固化与注册表、类型声明层、云端 adapter 抽象 / 凭据契约 / 飞书与腾讯 adapter / 能力位矩阵 / 持凭据实测 / 回归套件。

### 上线：从「能跑」到「能装、能发」
- **宿主挂载**：作为 DSH 客户端插件（ESM 宿主条目 + 客户端 bundle），打开表格文件即出现浮窗面板；修掉宿主挂载的四个坑（无 tab / 崩溃 invalid plugin / 空文件打不开 / 崩溃恢复把插件踢出 profile）。
- **安装与发布**：一键安装脚本（在线 `git clone + install.sh` / 离线 Release zip + `install.sh`），`DSH_PROFILE_DIR` 换 profile；GitHub Release 发布 v1.0.0 / v1.1.0 / v1.2.0（v1.0.0 为收官补齐的首个可上线版本初版，回填其 tag 与 Release），附 `dsh-workbench-<版本>.zip`。
- **CI 门禁**：GitHub Actions，ubuntu/windows × Node 20/22 四 job，跑 selfcheck + build 漂移检查 + 全量测试 + 两套 acceptance。
- **干净环境真机验证**：用真实 Release zip 解压到全新临时 profile，`install.sh` 一键装好、selfcheck 全绿。

### 能力：13 个一键动作 + 五步主流程 + 透视/流水线/真 LLM
- **动作**（每动作带类型化 `paramSpec` 封闭校验）：`extract` 提取字段、`swap` 调换两段字段、`conditional` 带条件增删、`function` 自定义函数计算（数值 / A1 公式两种写入）、`dedupe` 按主键去重、`replace` 子串替换、`fill` 填空白、`trim` 去空白、`case` 大小写、`affix` 前后缀、`sort` 按列排序、`highlight` 单元格标色（支持多条件→多色规则组）、**`sum` 汇总统计**。
- **`sum` 汇总/透视**：合计/平均/计数/最大/最小，可一次多列多聚合、可按单列分组、可**多级多列分组**（如 `部门;月份`），结果写入独立工作表「汇总」，**绝不改原数据表**。
- **多动作流水线批处理**：把配置好的动作逐步加入流水线，一键出组合预览、再一次性落盘。
- **一句话理解·可选接真 LLM**：可插拔（`lib/llm-adapter.js`，OpenAI 兼容协议，覆盖 DeepSeek/OpenAI/任意网关），离线默认关闭，网络错/超时/非 JSON 一律静默回落关键词，**永不阻断离线主路径、零第三方依赖**。
- **全生命周期按钮库**：执行后配方固化为命名按钮，可重命名/改参/删除/一键重跑，预置按钮随仓内声明式 JSON 分发。

## 关键设计决策

1. **不发散、不装样子**：输入框是**确定性关键词解析**，不是 LLM；能力位为 `false` 就禁用并提示，**不静默降级**（不把公式偷偷写成固定值、不把未验证类型塞进真实请求）。
2. **逐格预览、确认才落盘**：任何动作先出「解释 → 封闭校验 → 作用范围 → 影响预览（逐格 before→after）→ 确认」五步卡，确认前表格不动。
3. **绝不改原表（汇总类）**：`sum`/透视结果一律写进独立「汇总」sheet，原数据表一个单元格都不动；重复执行覆盖同名 sheet，结果稳定。
4. **能力位三维证据状态**：`verified-true` / `verified-false` / `unverified-default-false`；只有 `verified-true` 解锁动作，其余禁用并在预览里提示，不提供 opt-in 绕过。
5. **第一版条件闭包**：只支持 `字段 op 值`（`= ≠ > ≥ < ≤`），AND/OR、列间比较、包含/为空显式拒认并提示；v2 语法留触发指针，不预留扩展枚举。
6. **权限 defer**：无账号体系 / 分享链接 / 按钮级 ACL，配方随 git 权限，运行态仅本机使用者可见。

## 已知边界（维持不动）

- 云端四格能力位全为 `false`（腾讯三格负面已验证；飞书四格未验证 + 使用者豁免，保守记 false），未因链路跑通就重测成 true。
- 输入框不做自由自然语言编译（无 LLM 兜底时可接可插拔适配器，但默认离线）；透视不做「行 × 列」双向交叉/列转置报表。
- 细粒度权限、AND/OR 与 v2 条件语法、任意自然语言一步编译成函数——均 Out of scope，触发时另起 effort。
