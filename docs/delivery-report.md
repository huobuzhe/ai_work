## 一句话总结

把「建表 + 日常繁琐表格操作」收进一个工作台，先在**本地 Excel 零凭据**跑通最小闭环，再沉淀出一份**可交实现的云端 adapter 规格**（飞书优先）。两轮 effort 全部收官，验收全绿，工作树干净。

## 交付了什么

### 第一轮 — 本地 Excel 零凭据闭环
- **一张找路地图 + 5 张决策票**：确认能力边界（Skill/MCP 无法独立完成全链）、原型形态、第一刀切片（本地 Excel 最小闭环）、以及「能力位为 false 就禁用、不静默降级」的底线。
- **一份规格 + 20 张实施票**：核心闭环、模板库、公式重算、作用范围与条件、配方校验与预览卡、按钮固化与注册表、类型声明层，以及云端 adapter 抽象 / 凭据契约 / 飞书与腾讯 adapter / 能力位矩阵 / 持凭据实测 / 回归套件。

### 第二轮 — 云端 adapter 闭环
- **一张找路地图 + 4 张决策票**：飞书为第一梯队（低凭据门槛、真凭据端到端跑通）；能力位升级为**三维证据状态**（布尔 + 证据枚举 + 一手来源）；模板来源锁死仓内声明式清单；AND/OR 推迟 v2。
- **一份规格 + 6 张实施票**：唯一净新增代码 seam 是证据状态枚举，其余 5 票均为「验证既有、不加产品行为」——把两轮积累的边界用断言钉死。

## 关键设计决策

1. **证据状态三值**：`verified-true` / `verified-false` / `unverified-default-false`；只有 `verified-true` 解锁动作，其余禁用并在预览里提示，**不提供 opt-in 绕过**。
2. **不静默降级**：能力位为 false 就禁用，不把公式偷偷写成固定值、不把未验证类型塞进真实请求。
3. **模板来源唯一**：仓内声明式清单（git 作线上来源），不联网抓云端模板中心或 GitHub 文件。
4. **第一版条件闭包**：只支持 `字段 op 值`（`= ≠ > ≥ < ≤`），AND/OR、列间比较、包含/为空显式拒认并提示确认；v2 语法留带触发条件的指针，不预留扩展枚举。
5. **权限 defer**：无账号体系 / 分享链接 / 按钮级 ACL，配方随 git 权限，运行态仅本机可见。

## 已知边界（维持不动）

- 云端四格能力位全为 `false`（腾讯三格负面已验证；飞书四格未验证 + 使用者豁免，保守记 false），未因链路跑通就重测成 true。
- 细粒度权限、AND/OR 与 v2 条件语法、任意自然语言一步编译成函数——均 Out of scope，触发时另起 effort。
- 仓库 README 规格已解除搁置：用户说清方向句（「表格自动化工作台」）后，按既定四条边界写出仓库根单页 `README.md`（commit `b44244b`），5/5 人工验收全过，对应 issue 已关闭。
